# Excel Data Analytics Practice — Day 10

This folder contains my **Day 10 Excel practice** as part of my Data Analytics learning journey.

I have already practiced the Excel fundamentals, so this practice focuses on more advanced and interview-oriented Excel topics commonly used in Data Analyst roles.

## 📌 Topics Practiced

* LOOKUPs

  * XLOOKUP
  * VLOOKUP
* INDEX + MATCH
* SUMIFS
* Nested IF
* IFS
* Pivot Tables
* Pivot Table Slicers
* Basic data analysis using Excel
* Interview-style analytical questions

## 📊 Dataset

The practice is based on a **Sales Data** dataset containing information such as:

* Order ID
* Date
* Salesperson
* Region
* Product
* Category
* Units
* Unit Price
* Sales
* Profit
* Customer Type

The dataset is used to solve realistic business and Data Analyst interview-style problems.

## 🎯 Practice Objectives

The main objectives of this practice are:

* Improve my ability to use Excel lookup functions.
* Understand when to use XLOOKUP, VLOOKUP, and INDEX + MATCH.
* Practice conditional calculations using SUMIFS.
* Use Nested IF and IFS for classification.
* Analyze data using Pivot Tables.
* Use Pivot Slicers for interactive filtering.
* Solve practical, interview-style Excel problems.
* Improve my ability to choose the appropriate Excel function based on the problem.

## 📝 Practice Tasks

The exercises include:

1. Finding information using XLOOKUP.
2. Retrieving information using VLOOKUP.
3. Handling lookup errors.
4. Finding values using INDEX + MATCH.
5. Performing lookups using multiple conditions.
6. Using SUMIFS with one or multiple criteria.
7. Classifying records using Nested IF.
8. Classifying sales using IFS.
9. Creating Pivot Tables for sales and profit analysis.
10. Analyzing sales by Region, Category, and Salesperson.
11. Creating Pivot Table Slicers.
12. Building a small interactive sales analysis report.
