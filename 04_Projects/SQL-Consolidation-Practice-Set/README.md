# SQL Consolidation Practice — Data Analytics

## About This Project

This repository contains my SQL consolidation practice as part of my preparation for entry-level Data Analyst roles.

The goal is to revise and strengthen my SQL skills by solving 50 practical questions based on a retail sales database.

All queries are written independently to improve my problem-solving ability and prepare for technical interviews.

## Topics Covered

- Database and table creation
- INSERT, SELECT, UPDATE and DELETE
- Filtering and sorting data
- Aggregate functions: COUNT, SUM, AVG, MIN and MAX
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- CASE statements
- Window functions: RANK, OVER and PARTITION BY
- Business-oriented data analysis problems

## Database

**Database name:** `retail_analytics`

Tables used:

- `customers` — customer information
- `products` — product details and prices
- `orders` — order quantities, dates and statuses

## Repository Structure

Each SQL file covers a specific topic, from database setup and basic queries to joins, window functions and business problems.
